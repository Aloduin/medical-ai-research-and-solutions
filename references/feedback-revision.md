# 反馈修订

先找到本轮需要更新的需求、方案和证据版本。准确记录新反馈的来源、日期、影响及其当前确定程度。

| 反馈 | 第一个需要重做的判断 | 顺带核查 |
| --- | --- | --- |
| 临床研究问题变化 | 重写人群、任务、索引时点和输出，重新查证相关机制和方法 | 数据适用性、终点、评价、伦理范围及首期交付 |
| 数据、接口、权限变化 | 重新核查受影响的数据条件，收紧候选方案的可行性 | 能否改用其他数据、缩小试点，何时重启原路线 |
| 数据扩充、结果异常或相反证据 | 核查版本、标签、队列、漂移、泄漏和验证口径 | 之前结论的适用性、校准及后续验证的设计 |
| 业务目标、采购主体或团队变化 | 重写决策目标、用户和服务流程，按新目标比较机会 | 产品范围、责任人与成本、试点指标和付费假设 |
| 受众或交付定位变化 | 确认新受众要做的决定，据此选取内容和深度 | 证据口径、对外承诺和首期的表述 |
| 文字或版式调整 | 按原有事实和目标修订表达 | 核对数字、范围、授权表述及证据引用 |

当同一条反馈同时改变几个条件，从最早受影响的环节开始，再核查下游内容。对关键决定写明旧判断、变化依据、现在的决定和重新开启决策的条件。反馈是新假设时，保留可执行的验证。对引用已失效证据的承诺，同步撤下或收紧表述。
