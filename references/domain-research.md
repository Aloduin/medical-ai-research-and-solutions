# 专业调研

## 把问题写成可检索、可验证的形式

| 决策 | 问题定义 | 重点核对 |
| --- | --- | --- |
| 理解陌生临床场景 | 谁在什么时点做判断，依据、行动和后续观察是什么 | 临床机制、现行流程、部位或人群差异、医护交接 |
| 研究关联或干预 | 人群、暴露或干预、对照、结局、观察期 | 纳排、时间顺序、混杂、治疗影响与测量偏差 |
| 开发预测模型 | 人群、索引时点、可用输入、结局、预测窗、验证设置 | 预测时能获得的特征、参考标准、事件频率、上线时的使用方式 |
| 识别产品机会 | 用户、承担工作的角色、现有流程、采购者和预期改进 | 工作量、数据接入、服务交付成本、采用条件和采购实证 |

用概念关系解释任务涉及的机制，再拆到方法的测量量、假设和适用条件。对临床风险识别，先厘清模型改变哪一次复核或判断，以及人工如何处置结果。

## 检索和核验

- 确定疾病或业务名、同义词、数据类型、目标结局和方法。在检索较宽的领域时，先用指南和综述建立术语，再用原始论文追溯方法与结果。标明资料范围、检索日期与取舍，报告覆盖程度应与实际查证相符。
- 临床实践、政策及准入用适用地区和版本的指南、监管或卫生机构原文。算法与性能用论文正文、附录、试验记录和公开数据说明。产品能力用官方文档与实例。付费证据可来自采购或试点材料，核对金额、采购内容及范围。
- 围绕可能改变推荐的命题查找不一致结果、外部验证和部署失败。解释人群、事件定义、中心、设备、数据质量、基线或随访差异如何造成结果冲突。
- 每条关键证据保存标题、机构或作者、链接或项目文件位置、日期或版本、查证级别、支持的表述与可迁移范围。仅看过摘要时将支持范围限定在摘要。资料不全时标明缺口并说明能支持的最小结论。
- 从项目材料中摘取的数据条件以其实际证据为准。会议提出的接口需求、方案估算的样本量、文档上的字段、脱敏样例和实际统计分别记录。涉及院内材料的外部检索使用公开术语。

## 比较方法

| 比较要素 | 核查内容 |
| --- | --- |
| 机制与替代方案 | 用途、核心假设、输入输出、可解释性，以及现有流程或简单基线 |
| 数据与参考标准 | 对象、分析单位、设备、采样、日期与时间对齐、标注来源、窗长、有效观测和可获取性 |
| 验证设计 | 数据划分、调参/阈值/校准拟合所在的数据、独立时间段或外部队列、缺失和构成差异 |
| 性能与适用性 | 指标及其分母、区间、阈值、误报或漏报代价、失效条件、方法在本项目落地的条件 |

当同一个患者有多次记录或时间窗口时，划分和置信区间按患者或合适的独立单元设计。预处理、特征筛选、超参数、阈值和校准的拟合排除最终验证数据。按需要核对数据来源、采集批次及时间漂移，报告亚组或队列差异、区分度与校准。比较性能数值前核对任务、标签、样本构成和评估口径。

## 收敛为下一步

先回答决策问题。每个值得继续的假设写明人群与场景、依据、假设可能失效的条件、可观察的结果和最小验证办法。复杂任务附证据表与方法对比。按对决策的影响排列未知项，并写出获得什么结果会改变建议。
